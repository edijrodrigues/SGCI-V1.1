# SGCI V1.1

Sistema de Gestão para Cursos e Instituições

---

## Sobre o Projeto

O SGCI (Sistema de Gestão para Cursos e Instituições) é um projeto de estudo e evolução profissional desenvolvido com foco em:

* Modelagem de Dados
* PHP
* MySQL
* Arquitetura MVC
* Engenharia de Software
* DevOps

A versão V1.1 representa uma reconstrução estruturada baseada nos conhecimentos adquiridos durante o desenvolvimento do MVP Beta 0.

---

## Objetivos

* Consolidar conhecimentos em desenvolvimento web.
* Aprimorar práticas de modelagem de dados.
* Aplicar arquitetura MVC.
* Documentar integralmente o projeto.
* Evoluir gradualmente para práticas DevOps.
